# sky-courier 🦫🔮 🐈‍⬛ 🌙
Ein 3D-Liefer- und Flugspiel mit Hexe/ Zauberer als main character in Rust mit Bevy. Aufträge in Form von Paketen werden von zufällig generierten Villagern aufgegeben und die über die Stadt hinweg, auf dem Besen, gebracht.
